`./gradlew verify` passes, and the instrumented suite passes on an API 37 emulator. The performance benchmarks (DEV-031) were moved to 1.0.0 by the PO on 2026-10-24, so this milestone has no performance baseline. **Open:** TC-125 (offline cold start with cached images) needs menu images, which the sample data does not have, and a device run. The DEV-012 serial-number spike and the API 30 and 34/35 emulator runs are still open from earlier milestones.
